# pi-siliconflow

Расширение-провайдер SiliconFlow для pi coding agent.

## Установка

```bash
pi install ~/pi-plugins/pi-siliconflow
```

## Настройка

Экспортируйте ключ API:

```bash
export SILICONFLOW_API_KEY=sk-...
```

## Модели

- `siliconflow/deepseek-ai/DeepSeek-V4-Flash` (reasoning)

Выбор модели: `/model` внутри pi.
